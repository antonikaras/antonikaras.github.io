Real-time traffic lane and sign recognition system

University of Patras · 09/2016 - 06/2018

For my diploma thesis, we built a real-time computer vision system that detects traffic lanes and road signs to alert the driver. It warns the driver when the car drifts from the center of the lane. I compared different approaches for detecting and recognizing road signs, such as feature matching(SIFT, SURF), and machine learning based, SVM. The system was developed in both C++ and Python to evaluate the performance difference between the two languages. Built with OpenCV so it can run easily on embedded hardware, the system also connects to the car's CAN bus via the OBD-II port to display live vehicle data like speed and RPM.
