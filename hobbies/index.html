AI-based meal planning helper

08/2026 - now

To get more hands-on practice with databases and AI agents, I built a personal meal-planning tool around weekly supermarket flyers (e-tilbudsaviser). It uses an LLM pipeline to scrape the digital catalogs and store the discounts in a database, automatically tracking when flyers expire so it knows when to pull fresh offers. I also hooked up a Telegram bot to check system health and act as an interface to the database, along with a multi-agent setup that uses the weekly deals to put together affordable meal plans.
